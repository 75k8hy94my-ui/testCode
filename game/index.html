操作

徒歩: WASD / 矢印 = 移動、Shift = 走る、E = 施設・住民・自分の車を利用。一般住民にも近づいてEで話しかけると、その人の生活状況を確認できます。

自宅: 玄関から室内へ入り、ベッド・キッチン・シャワー・ソファへ歩いて近づき、E / ACTIONで利用できます。

コミュニティセンター: 曜日ごとの料理・手芸・体操講座に参加できます。開催時刻に入口でE / ACTIONを押してください。

ジム: 体調に合う運動を選べます。通うとトレーニング経験が上がり、新しいメニューが解放されます。

健康: 空腹・体力・清潔が長く危険な状態だと体調を崩します。生活を整えると少しずつ回復します。健康が30未満だと歩行速度が下がります。

若葉診療所: 南若葉住宅地にあります。8:00〜20:00に診察・処置（¥1,200）または重い不調向けの集中治療（¥2,800）を受けられます。

カフェの仕事: 体調と営業時間に合わせてシフトを選べます。勤務経験でロングシフトと昇給が解放され、勤務は1日1回です。

若葉便の配達: 自宅前の「若葉便 配達受付所」で1日3件まで受注できます。納品先でE / ACTIONから届けると報酬を受け取れます。期限後も減額で配達でき、受付所でキャンセルできます。

車: 乗車後に目的地を選ぶとルートは自動設定。W / ↑ = 加速、S / ↓ / Space = 減速・停止、E = 行き先変更・降車。

電車: 若葉線の駅入口でE / ACTION。電車が停車中なら乗車でき、乗車後は停車駅でE / ACTIONを押すと降車できます。

操舵は自動です。信号、制限速度、前走車との車間を守ると運転評価が上がります。

スマートフォン: 画面右上の「スマホ」またはPキーでいつでも開閉できます。生活状況を確認し、自宅の近くなら自宅へ移動できます。

スマホでは徒歩時は左スティック＋ACTION、運転時はBRAKE / ACCELを使います。

音: 最初のタップやキー入力で有効になります。右上の「音 ON / OFF」でいつでも切り替えられます。
