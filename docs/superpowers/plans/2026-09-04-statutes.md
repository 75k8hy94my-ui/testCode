# 六法機能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 主要6法を端末キャッシュから閲覧し、条文ごとのメモを既存暗号化Vaultへ自動同期できる六法画面を追加する。

**Architecture:** 法令本文は e-Gov 法令API XML をブラウザで整形し IndexedDB に保存する。条文メモだけを `vault-payload.js` の `statuteNotes` として既存Vaultへ含める。ホームから `statutes.html` に遷移し、PC右ペイン／スマホ下部シートでメモ編集する。

**Tech Stack:** Static HTML/CSS/JavaScript, IndexedDB, e-Gov 法令API v1 XML, existing MangaVault AES-256-GCM sync, Node 22 test runner.

**Spec:** `docs/superpowers/specs/2026-09-04-statutes-design.md`

## Global Constraints

- 対象は憲法・民法・会社法・刑法・民事訴訟法・刑事訴訟法。
- 商法は対象外で会社法を採用する。
- 条文本体はVault/Supabaseに保存しない。
- メモは既存暗号化Vaultに含め、平文でSupabaseへ保存しない。
- 通常閲覧では端末キャッシュを優先し、毎回e-Govへアクセスしない。
- `npm test` と `npm run verify:static` を完了条件とする。
