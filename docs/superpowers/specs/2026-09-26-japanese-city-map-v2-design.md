# City Days 日本都市マップ v2 設計

## 目的

v1 は道路自体は格子ではなくなった一方、地面・街区・建物配置・ランドマークの多くが旧600pxグリッド由来の考え方を残していた。そのため、曲線道路の周囲に建物が自然に形成された街ではなく、「曲げた道路を長方形の地区と少数のparcelへ重ねた地図」に見えやすかった。

v2 では、道路、徒歩経路、地区境界、オープンスペース、建物群、街路樹、ランドマークを同じ MapModel が所有する。ゲーム側はそのデータを描画・衝突・経路探索へ利用し、旧グリッドを都市形状の根拠にしない。

## 都市の骨格

架空の「若葉」地区を、東京西部の私鉄・JR沿線郊外に見られる都市形態を圧縮した構成とする。実在道路の複製ではない。

- 東西の高架鉄道に、西若葉・若葉・東若葉の3駅がある。
- 若葉駅周辺は駅前広場、幹線道路、商店街、中層建物が集積する。
- 駅から南西へ旧街道型の商店街が伸び、カフェ周辺から住宅地へ徐々に道路幅と建物規模が縮小する。
- 南部住宅地は直交格子にせず、T字路、曲線、短い接続路、袋小路を混ぜる。
- 北側は中央公園・神社・文教地区とし、自動車道路より徒歩の抜け道を多くする。
- 東側はスーパー等の沿道商業から住宅地へ移行する。
- 幹線道路は連続させるが、生活道路は必要以上に相互接続しない。

## MapModel が所有するもの

### nodes / edges

道路と徒歩経路のグラフ。車両経路、歩行者経路、信号、道路描画、道路面判定は同じ edge geometry を使う。

道路階層は主に以下。

- arterial: 幹線道路
- collector: 地区内の集散道路
- shopping: 商店街・駅周辺の車道
- residential: 住宅地生活道路
- alley: 狭い生活道路・袋小路
- park: 公園縁辺道路
- sidewalk / plaza / shopping-walk / greenway: 歩行者専用経路

細街路には中央線を描かず、arterial と一定幅以上の collector のみ道路中央標示を持つ。

### districts

長方形ではなく polygon で定義する。districtAt() も polygon 内包判定を使う。

### openSpaces

公園、神社林、学校グラウンド、駅前広場、駐車場、児童遊園等。建物生成から除外され、ゲーム側で用途ごとの地表表現を行う。

### buildingSites

建物は固定4parcelではなく、用途別 building zone から決定的に生成する。

生成時に以下を満たさない候補は捨てる。

- 道路・歩道の必要クリアランスと重ならない
- 鉄道高架直下へ建てない
- 施設と駅の必要空間を塞がない
- 公園・広場・学校・駐車場へ侵入しない
- 既存建物と過密に重ならない
- 指定district polygon内に建物中心が入る

住宅地は小規模戸建て主体、一部3階程度の小共同住宅。駅前・東商業地区は中層建物を主体とし、少数の高層建物を許容する。

### vegetation / landmarks

公園・神社・児童遊園の樹木位置はMapModelに保持する。樹木は徒歩経路からクリアランスを取る。

商店街アーチ、鳥居、学校表示、バスターミナル等も固定グリッド座標ではなく landmarks として地図データに置く。

## 描画順

1. 基本地面・海岸
2. district / openSpaces
3. 現行MapModelの道路
4. ナビ経路
5. 街灯・樹木
6. 建物
7. 施設
8. 鉄道・人物・車両等

これにより地区色や広場が道路を覆わないようにする。

## 維持すべき不変条件

- home / cafe / store / park / gym / library のIDを維持する。
- west / central / east の駅IDを維持する。
- 全施設入口同士が徒歩で到達可能。
- 全施設roadNode同士が車で到達可能。
- 全駅access位置は徒歩可能。
- 建物は道路面へ侵入しない。
- 少なくとも複数の袋小路とT字路を持つ。
- 施設・駅のセーブデータは mapVersion 不一致時に現行地図へ安全に移行する。
- 道路・衝突・経路探索・信号が別々の地図形状を参照しない。

## 非目標

実在の吉祥寺、三鷹、西荻窪等の道路形状をそのまま再現することは目的としない。日本の都市形態に見られる密度変化、道路階層、駅前と住宅地の関係を圧縮・再構成する。
