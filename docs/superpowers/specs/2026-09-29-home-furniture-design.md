# 自宅家具の購入・配置・生活行動 設計

## 目的と成功条件

自宅を既存の睡眠・料理・入浴・テレビ・手芸に加えて、自分で整えて日々使う生活空間にする。家具を店で購入し、自宅内で配置・移動・回収でき、家具ごとの行動が既存の時間・所持金・生活状態に反映される。配置と所持状態はセーブ・ロード後も維持され、既存セーブは家具なしの状態として読み込める。

## 採用方針

家具の品目・所持数・配置データ・購入処理を `game/home-furniture.js` の独立モデルに置き、既存の `game/game.js` は店舗、自宅内操作、描画、衝突判定、セーブ接続を担う。ゲームは静的 HTML/CSS/JavaScript のままとし、依存追加やビルド工程は導入しない。

初期カタログは本棚、こたつ、観葉植物の3種類とする。家具は店で購入する。家具ごとの所持数は最大12個、同時設置数も最大12個とする。設置済みの家具は自宅の家具配置モードで選択・移動・回転・回収でき、回収すると所持品に戻る。初期版では売却を行わない。家具操作はマウス前提にしない。WASD／矢印キーまたはタッチジョイスティックでプレビューを移動し、Rキー／配置モード内の「回転」ボタンで90度回転、Eキー／「設置」ボタンで確定、Escキー／「キャンセル」ボタンで終了する。家具を選ぶ・配置するUIは既存のアクション選択UIに接続する。

## 家具と行動

- 本棚：購入後、自宅内で「読書」を行える。所要時間35分。楽しさを上げ、エネルギーを消費する。
- こたつ：自宅内で「こたつで休む」を行える。所要時間30分。エネルギーと楽しさを回復する。
- 観葉植物：自宅内で「植物の手入れ」を行える。所要時間10分。楽しさを少量回復する。植物の成長や枯死など、別の時間経過システムは初期版には設けない。

具体的な価格・ステータス量は実装時に既存アクションのバランスを確認して決め、家具モデルに定数として定義する。すべての行動は既存の時間進行とneedsクランプを経由し、行動不能（未所持、未設置、資金不足等）で時間・状態を消費しない。

## 配置と衝突

家具配置は自宅内の20ワールド単位グリッドにスナップする。家具データは安定した家具ID、整数グリッド座標、90度単位の向きを持つ。配置可能領域は室内壁の内側とし、固定設備、既設家具、壁・間仕切りおよび出口への進入路と重なる配置を拒否する。回転後の幅・高さで判定する。無効な位置ではプレビューを不許可表示し、確定操作は状態を変更しない。

プレイヤーが使う家具は、家具の指定した操作位置まで歩いて到達できる配置だけを許可する。既存の歩行可能判定を使い、室内の20単位グリッド上で入口から操作位置までの到達性を確認する。自宅の既存固定設備の配置と操作を変えず、玄関から室内への通路を常に確保する。セーブに含まれる古い・不正な家具配置は正規化時にカタログID、1家具あたりの所持数、設置数、座標、向きを検証し、壁外や不正家具を無効なまま描画・衝突対象にしない。読み込み時に配置可能性を確認し、既存固定設備・壁・他家具と重なる、または通路を塞ぐ家具は所持品へ戻す。

## データと責務

`home-furniture.js` は凍結カタログ、初期状態、正規化、購入、配置・回収・回転、設置数／所持数上限、および家具行動の許可条件を純粋関数として提供する。購入処理は残高と時間を返し、ゲーム本体がその結果を反映する。モデル自身はDOM、Canvas、localStorage、時間進行に依存しない。

ゲーム状態に `homeFurniture` を追加し、初期化・ロード・通常セーブ・バックアップ用スナップショットの全経路で同じ正規化関数を使う。フィールドがない既存セーブは空の所持品・配置へ移行する。保存形式は既存ゲーム状態に追加するだけで、既存の保存キーや別機能の形式を変更しない。

店舗では各品目の価格・購入後の所持数・購入可否を表示し、購入成功時のみ残高を引き、既存の時間進行を適用する。屋内では設置済み家具をその座標と向きで描き、既存の近接アクションUIから対応する行動を提供する。配置・回収・回転も状態変更後に通常の自動保存対象となる。

## 検証

Node 標準テストで購入、資金不足、所持数上限、未知ID・不正値を含む正規化、配置数、回転・回収、既存セーブ移行、家具行動可否を検証する。統合テストでゲーム状態への保存・ロード接続と固定設備／出口／他家具への重なり拒否を検証する。headless Chromiumでデスクトップとモバイル相当の配置操作を実行し、設置・移動・回転・回収・行動、画面表示、console error/warning、pageerror、failed requestを確認する。画面画像でゴースト、家具、操作UIが判読でき、既存設備と重なっていないことを目視確認する。変更後は `npm test` と `npm run verify:static` を実行する。

## 範囲外

家具の売却、部屋の増築、自由な壁・床リフォーム、複数階、訪問NPC、家具の耐久・電気料金、植物の成長、家具のクラフトは含めない。コインランドリーとサークル深化はこの仕様とは独立した後続サブプロジェクトとして、それぞれ設計・実装・検証する。
