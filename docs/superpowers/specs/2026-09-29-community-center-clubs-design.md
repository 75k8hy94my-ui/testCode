# 若葉コミュニティセンター・定時サークル — 設計

## 目的

既存の技能講座だけでなく、地域の人と継続的に顔を合わせ、プレイヤーとNPC同士の関係が深まる週次活動を追加する。会場へ行って参加するだけでなく、対象NPCも予定に合わせて移動・参加し、会話に当日の活動が反映される生活ループにする。

## 体験

- コミュニティセンターのメニューに、次回時刻・参加費・予定メンバーが表示される。
- 週3回のサークルを開催する。Day 1を日曜として、Day 3（火）18:30「放課後ボードゲーム会」¥100／60分、Day 5（木）20:00「手しごととお茶の会」¥200／75分、Day 1（日）16:30「夕方のまち交流会」無料／45分とする。
- 予定メンバーは順に、アオイ・メイ・ハル、ソラ・ユイ・ナナ・トウマ、レン・カオリ・ダイチ。これにより現在の特別NPC10人全員がいずれかの活動に参加する。
- 受付は開始10分前から開始10分後まで。1イベントにつき同じDayで1回のみ参加できる。
- 成功時に費用を一度だけ支払い、規定時間を進める。プレイヤーの交流・楽しさを回復し、予定メンバーとの親密度を少し上げる。両者に既存の関係性があるメンバー同士は、その関係値も少し上がる。
- 参加時に所持金と参加記録を再検証する。受付外、参加済み、所持金不足では時間・お金・進行を変更しない。
- サークル参加記録はスナップショットに保存する。旧セーブに記録がなくても空として読み込む。
- 予定メンバーは開始前の移動時間を見込んでセンターへ向かう。勤務中、深夜、体調不良、所持金不足のNPCは参加しない。到着時に時刻・開催回・費用条件を再検証する。
- センターでサークルに参加中のNPCとは会話可能で、会話文に活動の話題を反映する。

## 週次イベントと効果

| ID | 開催 | イベント | 参加費 | 時間 | 参加メンバー |
|---|---|---|---:|---:|---|
| `board-game` | 火 18:30 | 放課後ボードゲーム会 | ¥100 | 60分 | aoi, mei, haru |
| `handcraft-tea` | 木 20:00 | 手しごととお茶の会 | ¥200 | 75分 | sora, yui, nana, toma |
| `neighborhood-mixer` | 日 16:30 | 夕方のまち交流会 | 無料 | 45分 | ren, kaori, daichi |

全イベント共通で、プレイヤーの交流+12、楽しさ+12、体力-4、各予定メンバーとの親密度+2、参加メンバー間に定義済みのNPC関係があれば関係値+1とする。値は既存の上限100でクランプする。

## アーキテクチャ

- `game/community-center.js` をイベント定義、開催回計算、参加可否、NPCの開催前行動機会、進行記録の正規化の唯一の責任者とする。講座APIは後方互換を維持する。
- `game/game.js` はセンター画面、プレイヤー効果、NPC行動候補・到着再検証、セーブ／ロード、NPC同士の既存関係値との接続を担当する。
- `game/social-npc-system.js` は `community_club` 活動中の会話を活動固有の話題にする。新しい外部依存や別施設は追加しない。
- ゲーム進行データは既存の `communityCenter` スナップショット領域にまとめる。未指定の新フィールドは正規化で安全な空状態にする。

## 制約と失敗時

- 静的HTML/CSS/JavaScriptを維持し、本番依存を追加しない。
- 受付失敗・二重クリック・古い保存データでは料金、時間、関係性を変更しない。
- 人間の参加効果は参加済みの一意キー `(clubId, day)` を使い一度だけ適用する。
- NPCの行動は既存の通勤ルートとスケジュールを利用し、会場での直接座標変更・瞬間移動を使わない。
- `game/character-showcase.html` および関連するローカルテスト用画像は対象外で、コミット／Pushに含めない。

## 検証

- `tests/community-center.test.mjs` で週次開催、受付境界、費用、重複参加、進行移行、NPC選択・到着時検証を確認する。
- `tests/social-npc-system.test.mjs` でサークル中の会話内容を確認する。
- `tests/game-runtime.test.mjs` でメニュー、再検証、時間・費用・親密度、NPCの移動とセーブ復元を確認する。
- CLI headless Chromiumで実参加、重複防止、NPC移動、モバイル表示を操作し、console/pageerror/failed requestがないことを確認する。
- 最後に `npm test` と `npm run verify:static` を実行する。

## 成功条件

3イベントが週次スケジュールに沿って参加可能になり、参加が一回だけ確定し、時間・所持金・プレイヤーの状態・NPCの関係に反映される。対象NPCが開始前に実際の歩行ルートでセンターへ移動し、サークル中は活動固有の会話を返す。新旧セーブが安全に読み込まれ、デスクトップとモバイルで操作できる。
