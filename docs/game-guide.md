# 若葉の街 ゲーム説明書

## ゲームの概要

プレイヤーは若葉の街で生活し、徒歩や電車から始め、序盤に中古車を購入して移動範囲を広げられます。住民と話し、施設を利用し、仕事や配達に取り組み、自宅では家具を配置できます。ゲーム内の時間や住民の予定に応じて、街の様子が変化します。

## 基本操作

### PC

- `WASD` または矢印キー：徒歩移動
- `Shift`：走る
- `E`：近くの住民・施設・自分の車を利用する
- `P` または画面右上の「スマホ」：スマートフォンを開閉する
- 画面右上の「操作」：操作説明を開く
- 画面右上の「音 ON / OFF」：音声を切り替える

車に乗っている間は、`W` / `↑` で加速、`S` / `↓` / `Space` で減速・停止します。`E` で行き先変更または降車を行います。操舵と案内ルートの走行は自動です。

### モバイル

- 左下のスティック：徒歩移動
- `RUN`：走る
- `ACTION`：近くの対象を利用する
- 運転中の `ACCEL` / `BRAKE`：加速・減速
- `ROUTE`：行き先メニューを開く
- 右上の「スマホ」：スマートフォンを開閉する

画面サイズに合わせてゲーム画面を表示します。スマートフォンはPCでは画面右下、モバイルでは画面内に全体が収まる配置です。

## 街を歩く・住民と交流する

住民や施設に近づいて `E` / `ACTION` を押すと、会話や利用ができます。住民との会話では、その人の生活状況を確認できます。会話できる住民の一部は、時間帯、予定、他の住民との関係、プレイヤーとの会話に応じて行動を変えます。会話中に止まるのは会話相手だけで、街の時間や他の住民・車の動きは続きます。

歩行者は道端を自由に直線移動するのではなく、歩道、横断歩道、施設へのアクセス経路をつないだ経路に沿って移動します。横断歩道では、信号の有無と周囲の車を考慮します。信号のない横断では歩行者が安全を確認して横断の意思を示し、車側も横断者へ譲ります。

## 車・交通

自宅近くに停めてある中古車に近づいて `E` / `ACTION` を押すと、¥10,000で購入できます。購入前も徒歩や電車、仕事、交流、地域活動を利用できます。購入後に車へ近づくと乗車でき、目的地を選ぶと自動でルートが設定されます。カフェの通常シフト1回、または配達などで購入資金を得られます。

信号、制限速度、前走車との車間に注意して運転してください。NPC車は車線変更や交差点で滑らかに進路を変えます。路肩の駐車車両などで進めない場合、条件が安全なら後続車は隣の通行帯を使って追い越します。対向車や交差点内の車両との衝突を避けるため、安全な隙間がないときは待機します。

街の横断歩道は歩行者の経路、車の譲歩判断、道路上の描画で共通のデータを使用します。

## 自宅

玄関から自宅に入ると室内マップへ移動します。室内では街と同じ基準の表示倍率を保ちつつ、歩行速度が街より少し速くなります。玄関から街へ戻れます。

家具ボタンから購入済みの家具を配置・移動できます。

- PC：矢印キー / `WASD` で家具を移動、`R` で回転、`E` で配置確定、`Esc` でキャンセル
- モバイル：左スティックで移動し、`回転` / `配置` / `キャンセル` を使用

家具の見た目、配置可能範囲、衝突判定は同じ家具形状データに基づいています。配置後は家具に近づいて利用します。

## スマートフォン

「スマホ」または `P` キーでいつでも開閉できます。生活状況を確認でき、自宅の近くでは自宅への移動機能を利用できます。スマートフォンを開いている間もゲーム世界は進行します。

## 施設・生活

- **コミュニティセンター**：開催時刻に入口で操作すると、曜日ごとの料理・手芸・体操講座に参加できます。
- **ジム**：体調に合った運動を選べます。経験を積むとトレーニングメニューが増えます。
- **若葉診療所**：南若葉住宅地にあります。8:00〜20:00に診察・処置（¥1,200）または集中治療（¥2,800）を受けられます。
- **カフェ**：体調と営業時間に合わせてシフトを選べます。勤務経験で長いシフトや昇給が解放され、勤務は1日1回です。
- **若葉便**：自宅前の配達受付所で1日3件まで受注できます。納品先で操作すると報酬を受け取れます。期限後も減額で配達でき、受付所でキャンセルできます。
- **若葉線**：駅入口で乗車し、電車が停車している駅で操作すると降車できます。
- **健康**：空腹・体力・清潔が危険な状態で続くと体調を崩します。生活を整えると回復します。健康が30未満では歩行速度が低下します。

家賃はDay 8から7日ごとに¥12,000です。支払いが足りない場合、所持金を超えて引き落とされず、不足分は利息なしで14ゲーム日の猶予があります。猶予後も住居や行動は制限されず、収入を得てから自宅前で払える範囲を返済できます。

## 表示・進行状況について

ミニマップは道路・建物・緑地などの街区情報をもとにした地図です。ゲーム画面のカメラに合わせてプレイヤーの位置と向きを確認できます。

ゲームの進行は、ログインしてVault（保管庫）を開いている間、既存の同期機能を使って約30秒ごとに自動保存されます。別の端末で続ける場合は、同じアカウントでVaultを開いてください。Vaultを開いていない場合や同期に失敗した場合は、画面上部に状態が表示されます。同期を利用できない状態では、ページを閉じる前にVaultを開いて同期状態を確認してください。

## 仕組みの補足

歩行者は型付きの経路区間（歩道・横断歩道・施設アクセス）で目的地へ向かい、古い経路データを読み込んだ場合も現在の道路網に合わせて再計画します。信号なし横断では横断要求と車の譲歩予約を管理し、歩行者・車の双方が相手を待ち続ける状態を避けます。

建物は道路との接面から向き・入口・配置範囲を決めます。自宅では家具の描画形状と衝突形状を共通データから作ります。車の旋回・車線変更は見た目だけを補正せず、実際の位置と向きを連続的に更新します。その位置を車間距離・衝突判定・交差点の通過判断に使います。
