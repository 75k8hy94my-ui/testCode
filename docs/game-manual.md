# City Days 遊び方ガイド

このガイドは、現在の `game/index.html` に実装されている機能と操作を説明します。街を自由に歩き、仕事や施設を利用しながら、若葉の街での暮らしを組み立ててください。決まったクリア条件はありません。

## まず覚える操作

| 操作 | PC | モバイル |
| --- | --- | --- |
| 歩く | WASD または矢印キー | 画面左のスティック |
| 走る | Shift | RUN |
| 近くの施設・人・車を利用 | E | ACTION |
| スマートフォン | P または画面右上の「スマホ」 | 画面右上の「スマホ」 |
| 操作説明を開く | 画面右上の「操作」 | 画面右上の「操作」 |
| 音を切り替える | 画面右上の「音 ON / OFF」 | 同じボタン |

近くに使えるものがあると、画面に操作案内が表示されます。案内が出てからE / ACTIONを押してください。行動の選択画面を閉じるときは「×」を押します。

### スマートフォン

スマートフォンはいつでも開けます。時計、天気、生活状態、所持金、目的地、駅、知り合いなどを確認できます。「マップ」から目的地を選ぶと徒歩ナビが始まり、車に乗っているときは運転目的地になります。友達の案内は、相手の現在地が公開されている場合に利用できます。

## 暮らしの状態と時間

画面の生活メーターでは、空腹・体力・清潔・交流・楽しさ・健康を確認できます。食事、休息、入浴、仕事や運動などで状態が変化します。空腹・体力・清潔が長く低いと体調を崩すことがあり、健康が30未満になると歩く速度が落ちます。

行動や移動でゲーム内の時間が進みます。仕事・講座・電車などは開始時刻や営業時間を確認してから利用しましょう。家賃はDay 8から7日ごとに¥12,000です。支払いが足りない場合は利息なしの滞納となり、14ゲーム日の猶予があります。猶予後も住居や行動は制限されず、収入を得てから自宅前で返済できます。

## 自宅

自宅の玄関から屋内マップへ入れます。家具ボタンから購入済みの家具を配置・移動・収納できます。配置中は矢印キー／WASDまたは左スティックで位置を調整し、R／「回転」で向きを変更、「E」／「配置」で確定、「Esc」／「キャンセル」で中止します。通路や出入口をふさぐ配置はできません。

家具や部屋の設備に近づいてE / ACTIONを押すと、利用できる行動が表示されます。

- キッチンで食材を使って料理する。完成した料理は持ち歩いて後で食べられます。
- クローゼットで所有している服に着替えたり、それぞれの服の清潔度を確認したりする。
- 手芸机でキットを使って作品を作る。作品は住民への贈り物にできます。
- テレビを見て気分転換する。
- シャワー、ベッド、ソファで身支度・睡眠・休息をする。
- ペットを迎えた後は、自宅で世話をする。

## 服とコインランドリー

服はスーパーで購入でき、自宅のクローゼットで着替えられます。各衣装は個別に清潔度を持ち、現在着ている服だけがゲーム内時間とともに汚れます。着替えても、それぞれの服の状態は保持されます。クローゼットには清潔度と「清潔」「少し汚れています」「洗濯推奨」の目安が表示されます。

汚れた服は「若葉コインランドリー」で洗えます。徒歩で入口まで行き、E / ACTIONから現在着ている服を選んでください。

- 料金：300円
- 所要時間：ゲーム内30分
- 営業時間：6:00〜23:00（閉店までに終わる時間が必要です）
- 洗濯後：対象の服の清潔度が100%になります

すでに清潔な服、料金不足、営業時間外、閉店までに終わらない場合は利用できません。その場合、所持金や時間は消費されません。身体の「清潔」メーターとは別の仕組みです。

## 街の施設

施設の入口でE / ACTIONを押すと、利用できるサービスと条件が表示されます。料金・営業時間・体調条件がある行動は、選択画面の案内を確認してください。

| 施設 | できること |
| --- | --- |
| スーパー MARCHÉ | 食料品、衣装、手芸キット、持ち歩き用の食事、傘、家具などを購入する |
| カフェ LUNE | 体調に合わせてシフト勤務をする。経験を積むと長い勤務や昇給が解放される |
| 若葉ゲームコーナー | 1回300円のクレーンゲームで景品を集め、コレクションを確認する |
| 中央公園 | 釣りをする。釣った魚は料理にも使える |
| CITY GYM | 体調に合う運動を選び、トレーニング経験を伸ばす |
| 市立図書館 | 本を借りて読み、読書の進行や返却状況を確認する |
| 若葉コミュニティセンター | 曜日・時刻ごとの料理、手芸、体操講座やサークルに参加する |
| 若葉湯 | 入浴やサウナで清潔・体力・楽しさなどを整える |
| 若葉コインランドリー | 着用中の服を洗う。詳しくは「服とコインランドリー」を参照 |

| わかば動物保護センター | 条件を満たして犬か猫を迎える |
| 若葉線の駅 | きっぷまたは一日乗車券を購入して電車に乗る |

## 住民・友達・ペット

街の住民に近づいてE / ACTIONを押すと、その人の様子を確認できます。交流可能な住民とは会話や一緒に過ごす行動ができ、親密度や住民どうしの関係が変化します。特別な住民は時間帯や予定によって行動場所が変わることがあります。スマートフォンから連絡先や案内を確認できます。

保護施設で犬か猫を迎えると、自宅で世話ができます。ペットフードを用意し、犬とは散歩にも出かけられます。散歩中はペットと帰宅するまで車や電車を利用できません。

## 車と電車

### 車

自宅近くに停めてある中古車のそばでE / ACTIONを押すと¥10,000で購入できます。購入前も徒歩や電車、仕事、交流、地域活動を利用できます。購入後に車へ近づいて操作すると乗車でき、目的地を選ぶとルートが設定されます。カフェの通常シフト1回、または配達などで購入資金を得られます。操舵は自動です。

- W / ↑：加速
- S / ↓ / Space：減速・停止
- E：行き先変更、または停止して降車
- モバイル：BRAKE、ROUTE、ACCEL

信号、制限速度、前の車との車間を守ると運転評価が上がります。燃料がなくなる前に若葉石油で給油してください。携行缶を用意して補給する方法もあります。

### 電車

駅入口でE / ACTIONを押して乗車券を購入します。電車が停車しているときに乗車でき、到着した駅でE / ACTIONを押すと降車できます。モバイルの徒歩移動は左スティック、行動はACTIONを使います。

## 保存と再開

ログインしてVault（保管庫）を開いている間、ゲームの進行は既存の同期機能で約30秒ごとに自動保存されます。別の端末では同じアカウントでVaultを開いてください。Vaultがロック中、または同期に失敗した場合は画面上部に状態が表示されます。同期できない状態でページを閉じる前に、Vaultを開いて保存状態を確認してください。
